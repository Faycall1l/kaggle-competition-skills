# A gradient-boosted spatio-temporal imputer beats the shipped temporal-pair rule by +0.025 S_state

Date: 2026-10-25
Competition: 2026-ieee-big-data-traffic-flow-bench
Finding: The shipped reconstruction of a blanked Task 1 cell is the equal-weight mean of the nearest observable temporal pair (horizon 6-12 slots) with a rare topological fallback. Replacing only that rule with a `HistGradientBoostingRegressor` over 33 features - topological upstream/downstream speeds and flows, their one-step temporal neighbours, ±6/12-slot lags, a 2/4-link local speed mean, congestion context, density companions (flow/speed), and the link's weekday x 5-minute-slot profile - scores S_state 0.9333 against 0.9079 for the shipped rule, on the same held-out days and with the same official arithmetic (0.54*S_speed + 0.46*S_flow_per_lane, macro mean over R1/R2/R3). Speed RMSE falls 33% (2.82 -> 1.90 average) and flow RMSE 23%. The gain is not uniform: R2 (the mid-mask regime) gains most (+0.046), R3 least (+0.008) because the shipped rule already reaches 1.1 km/h there.
Evidence: D12_I5_N, profile+fit on 2030-06-01..20, scored on 2030-06-21..30 with `score_subset.py` (bit-identical to `score_task1.py`): champion+conserve 0.9079 (R1 0.9050, R2 0.8690, R3 0.9498) vs model+conserve 0.9333 (R1 0.9366, R2 0.9110, R3 0.9522). Raw model without conserve 0.9350. Cross-month transfer (fit June, predict December, same panel) reproduces the same -33%/-23% RMSE ratios.
Applies when: a masked-state task is scored on RMSE against a physically smooth field. The neighbour structure must come from the corridor topology table (`lwr_mainline_topology.csv`), not from the pivot's column order, which is sorted by link id; diagonal temporal neighbours (the links' own neighbours at the adjacent slot) and continuity features are what carry the gain. Ridge regression on the same features is worse than the baseline - the relationship is strongly nonlinear.
